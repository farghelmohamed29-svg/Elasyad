# الصياد التعليمية — EL SAYAD ACADEMY

هذه نسخة أولية (Prototype) لواجهة منصة تعليمية باللغة العربية، متجاوبة مع الهاتف والكمبيوتر.

## الموجود حاليًا
- واجهة عربية RTL متجاوبة.
- اختيار المرحلة والمادة.
- بطاقة درس تجريبية.
- زر إكمال درس مع حفظ محلي على نفس المتصفح.
- سؤال اختيار من متعدد وتصحيح فوري.
- ملفات PWA أساسية للتثبيت والتخزين المؤقت عند استضافتها عبر HTTPS.

## غير موجود بعد
- تسجيل دخول حقيقي أو قاعدة بيانات مشتركة بين الأجهزة.
- لوحة إدارة حقيقية لإضافة المناهج.
- فيديوهات ومحتوى مناهج حقيقي.
- مساعد ذكاء اصطناعي مربوط بخادم.
- الدفع الإلكتروني والاشتراكات.
- ضمان تنزيل كل محتوى الفيديو دون إنترنت.

## تجربة محلية
افتح `index.html` في متصفح حديث. معظم عناصر الواجهة ستعمل، لكن PWA وService Worker يحتاجان عادة إلى HTTPS أو localhost.

## نشر مجاني مبدئي
يمكن نشر الملفات الثابتة على GitHub Pages من مستودع عام:
1. أنشئ حسابًا على GitHub.
2. أنشئ مستودعًا باسم `el-sayad-academy`.
3. ارفع الملفات الخمسة الأساسية: `index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js` (ويمكن رفع README).
4. من Settings ثم Pages، اختر النشر من الفرع الرئيسي ومن المجلد الجذر.
5. انتظر ظهور رابط الموقع في إعدادات Pages.

## ملاحظات أمان
- لا تضع مفاتيح API أو كلمات مرور أو مفاتيح الدفع في JavaScript العام.
- قبل استقبال طلاب حقيقيين، أضف قواعد أمان للبيانات، ومصادقة مناسبة، وسياسة خصوصية وموافقة ولي الأمر عند الحاجة.
- افحص شروط الخدمات المجانية وحدودها قبل إطلاق الخدمة.
